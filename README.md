# Puppet Motion Studio

نسخة أولية لمنصة تحريك 2D بصريًا: المستخدم يتعامل مع الشخصية مباشرة، بينما الـRig ومفاهيم العظام مخفية. تدعم Keyframes وTimeline، وتستخدم الشخصية المرفوعة كموارد PNG مباشرة.

## التشغيل

لا توجد مكتبات واجهة خارجية. للتجربة محليًا:

```bash
python -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## GitHub Pages

ارفع المشروع إلى مستودع GitHub مع فرع `main`. ملف `.github/workflows/pages.yml` ينشر المشروع تلقائيًا إلى GitHub Pages.

## موارد الشخصية

الصور موجودة في `public/assets/character-01/`، والنسخة الحالية تستخدم:

- `01_head.png`
- `02_body.png`
- `03_right_arm.png`
- `04_left_arm.png`
- `05_right_leg.png`
- `06_left_leg.png`

ملفات PNG الأصلية كانت تحتوي أصلًا على قناة Alpha. تم فقط إسقاط الهالة شديدة الانخفاض حول الخلفية حتى تبقى الخلفية شفافة.

## الخطوة التالية

هذه النسخة هي أساس قابل للتوسعة. المرحلة التالية تكون تحويل التحكم من Transform مباشر إلى IK مخفي فعلي: سحب اليد/القدم يصبح هدفًا، والنظام يحسب دوران المفاصل تلقائيًا مع الاحتفاظ بنفس الواجهة والـTimeline.
